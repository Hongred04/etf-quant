# 把回撤压到 20% 以下：核心-卫星方案

> 由 `python scripts/combo_report.py` 生成，数字全部来自真实回测（含换手成本）。
> 区间 2021-06-02 ~ 2026-11-03（A 股核心篮子 4 只都有完整数据的起点）。

## 结论

**核心 50% + 卫星 50%：CAGR 12.1%，最大回撤 -19.4%，Sharpe 0.69，Calmar 0.62。**

对照纯卫星（S4 满仓）：CAGR 12.9%、回撤 -35.1%、Calmar 0.37。

收益少 **0.8pp**，回撤少 **15.7pp**，Calmar 提升 **69%**。

关键对比是**另一种压回撤的方法**（固定降敞口到 0.5，见 `docs/drawdown.md`）：
同样把回撤压到 −18.8%，但 CAGR 只有 6.9%、Calmar 0.37。
本方案的 Calmar 是它的 **1.7 倍**。

## 为什么这有效，而止损/熔断无效

两条腿的日收益相关性只有 **0.23**。池内 211 只宽基/主题/行业 ETF 彼此相关性 0.96~0.98，加进去等于没加；红利低波是真正不同步的一条腿。

组合的波动按相关性衰减、收益近似相加，所以复利效率提升——这是**分散化的数学收益**，不是择时。止损和熔断做不到这一点：它们只是在同一条收益流上截断，截掉的下跌同时也截掉了随后的反弹。

## 核心腿是什么

等权持有以下 4 只（每只 12% 当 core_weight=0.5，在调仓日再平衡）：

- `sh512890` 红利低波ETF华泰柏瑞
- `sh515450` 红利低波50ETF南方
- `sh515300` 300红利低波ETF嘉实
- `sz159307` 红利低波100ETF博时

选它们的理由不是挑出了最好的 4 只，而是红利低波这一类整体有效——单只选择会引入挑选偏差。用 7 只（含港股）的等权篮子做过对照，结论方向一致，但港股有 QDII 溢价与额度风险，默认只用 A 股 4 只（`--core-basket ah` 可切换）。

## 风险与边界

1. **这是风格暴露，不是 alpha。** 红利低波在 2023-01~2024-09 贡献正收益，但 2024-10 之后明显转弱。风格持续转冷时，组合收益会低于纯卫星。
2. **收益上限被核心腿压住。** 核心腿是始终在场的低波资产，牛市里它跑不过动量腿。要更高收益就得提高卫星比例，回撤也会跟着回来。
3. **样本**：2021-06 起 4.4 年，含一轮红利大牛市和一轮动量大牛市。两种风格各出现过一次，但没有经历过两者同时长期低迷。
4. **核心腿不择时**是有意设计：它能在卫星腿亏钱时提供正收益，靠的正是始终在场。给它加趋势过滤会削弱分散作用。

## 怎么用

```bash
# 生成含核心腿的完整清单（核心 50% + 卫星 50%）
python scripts/run_signal.py --core-weight 0.5

# 用港股红利低波增强核心腿（收益更高，有溢价风险）
python scripts/run_signal.py --core-weight 0.5 --core-basket ah

# 回到纯卫星（默认，不改变原有行为）
python scripts/run_signal.py
```

清单里核心腿的 4 只权重相同，卫星腿按 S4 信号等权。核心腿每期调仓时等权重置，换手很低（组合年换手从 25.8x 降到 13.2x）。

若要进一步压低回撤，可叠加 `--risk-scale`：
`--core-weight 0.5 --risk-scale 0.8` 会把总暴露降到 80%，回撤更低、收益也更低。
