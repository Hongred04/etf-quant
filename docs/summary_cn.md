# 结论速览

> 给不想读 8 万字技术文档的人。
> 所有数字都能在 `docs/README_full.md` 对应小节和 `output/experiments/` 里查到出处。
> 写于 2026-11-02，覆盖 7.1–7.26 全部实验。

## 一、这是什么

一套**A 股 ETF 轮动策略**：每 5 个交易日，从 260 只 ETF 里挑动量最强的 3 只等权持有；
用沪深300 趋势做闸门，跌破时把权益仓位砍半、另一半买债券。

代码、数据、回测、界面全部可复现（`python server.py` 起本地控制台）。

## 二、能赚多少

**三个数字，含义完全不同，不要混用。**

| 数字 | 值 | 含义 |
|---|---|---|
| 样本内回测 | **16.99%/年** | 参数在同一段历史上挑过，是上限 |
| 对外口径 | **11%~13%** | 扣掉"挑参数"后的中枢，可对外引用 |
| 95% 置信区间 | **[−2.74%, +42.20%]** | 换一段历史可能落在哪 |

区间宽度 44.9pp，是点估计的 2.6 倍。**两个概率必须知道**：

- **亏钱的概率 5.0%**
- **跑不过"直接买沪深300"的概率 16.9%**

风险侧：最大回撤 −28.86%（样本内），自助法下最坏可到 **−64.8%**；
最长水下期 **3.15 年**（2021-09 → 2024-11）。

## 三、什么时候行，什么时候不行

**主场：低波上涨。** 2024 年以后超额几乎全部来自这段。

**客场：结构性牛市。** 2019–2021 跑输沪深300 **9.3pp**——闸门降仓，牛市里天然跟不上。

**阴跌（2022 型）**：闸门有效。下跌市 814 天里，策略累计 −41.2%，沪深300 −53.0%，
同期满仓的动量基线 −45.3%。**亏得最少、波动最低、回撤最浅**，但夏普看起来更差
（负收益时低波动会被夏普惩罚，这是数学性质，不是策略变差）。

一句话：**震荡与熊市抗跌，牛市跟涨不足。不是全天候。**

## 四、什么条件下别用

三条，任一不满足，上面的数字都不适用。

| 约束 | 门槛 | 不满足会怎样 |
|---|---|---|
| **能开盘成交** | 开盘集合竞价或开盘后几分钟内下单 | 只能收盘成交 → 年化 **3.9%**，不如买指数 |
| **资金规模** | 100–500 万 | 1000 万约 5% 交易买不满；1 亿时 15% |
| **单边成本** | ≤0.10% | 0.20% → 11.7%；**0.30% → 6.6%，低于买指数** |

第一条最致命。策略的全部超额集中在"信号日收盘 → 次日开盘"这几小时，
**晚几个小时，超额就没了一半以上**。

## 五、已经走死的路（省得再试）

| 方向 | 结论 | 出处 |
|---|---|---|
| 加因子（多因子、残差、低波、缠论、均线、52周高、元标签） | 全部否或打平 | 7.1 / 7.6 / 7.6r / 7.7 / 7.8 / 7.9 / 7.12 / 7.13 |
| 换择时（ERP、慢变量、个券止损） | 否或中性 | 7.17 / 7.18 |
| 扩大候选池 | 否，反而全面变差 | 7.19 |
| 溢价尾部过滤 | 有效但伤回撤，卡玛下降 | 7.21 |
| 概率化 regime（HMM） | 否，预测方向反了 | 7.26 |
| 降换手省钱 | 不划算，省的钱抵不过选股变差 | 7.5 |
| 加杠杆 | 提数字不提质，卡玛不变 | — |

**为什么这些都不行**：信号本身很弱。R20 的横截面 IC 只有 **0.02**（信噪比 1:20），
20 日就归零、40 日转负。三处独立检验（HAC alpha t=1.38、三因子 alpha t=1.54、IC 的 t 值）
指向同一件事：**信号是真的，但强度不够**。

所以这策略的本质是：**弱信号 + 强执行 + 强择时**。靠集中持仓（3 只）、开盘快速成交、
闸门择时三件事叠出收益，不是靠选股准。

## 六、唯一还有价值的验证

**前向。** 回测已经在同一段历史上被榨干了，继续挖只会挖到过拟合。

具体做法：`data/signal_archive.csv` + 「实盘跟踪」页已经在记录每期真实信号，
跑满 3–6 个月后，看纸上净值和回测差多少。这是唯一不依赖"同一段历史"的证据。

## 七、诚实的自我评价

这几天查出**五次同类分析错误**，全部是"没检查口径就下结论"：
日频快照当成交事件、归一化净值当价格、小样本当规律、负收益区间用夏普、
算术年化当几何。已立两条硬规则进 `docs/strategy_dd.md` 闸门 6。

**这意味着上面的数字也可能还有没查出来的口径问题。** 用它们做决策时，
请按"这是当前证据下的最佳估计"来理解，而不是"这是事实"。

已知无法修复的一项：标的池的成员资格由**今天的成交额**决定，
历史缩量/清盘的 ETF 从未进入回测。偏差方向未知。
