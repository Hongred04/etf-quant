> 本文件由 `python scripts/dd_frontier.py` 生成，数字不手写。

基线（完全按信号执行）：CAGR **12.5%**，MaxDD **-35.2%**，Sharpe 0.53，Calmar 0.36。

## 结论先说

**只有降低风险资产暴露能达到目标，而且 Calmar 不变**——也就是说这是一次风险预算的选择，不是模型改进。所有熔断类方案都没能把回撤压到 20% 以内。

原因有二：① 覆盖只在**调仓日**（每 5 个交易日）评估，而回撤往往在几天内完成；② 触发后切到空仓会让净值无法恢复，解除条件永远不成立（平均仓位掉到 3%）。把解除条件改成「N 日后」或「站上 MA60」能避免锁死，但回撤仍在 −22%~−27%。

另一项检查：把持仓从 3 只分散到 5/6/8 只，MaxDD 分别是 −30.6%/−35.2%/−36.5%，**分散对系统性回撤无效**。

## 建议

若 20% 是硬约束：用 **A 固定敞口 0.50**，CAGR 6.9%、MaxDD -18.8%、Sharpe 0.46。代价是年化少赚约 5.6pp，且收益会低于沪深300 全收益的 7%——本质是用收益换波动。

启用方式（默认关闭，不改变现有信号）：

```bash
python scripts/run_signal.py --risk-scale 0.5   # 本次生成按 50% 风险预算
ETF_RISK_SCALE=0.5 python scripts/run_signal.py  # 或用环境变量
```

缩放后的目标权重之和小于 1，差额留现金；界面的「买入清单」会直接体现。
