# 试验预注册 7.21 — 加仓时的溢价尾部过滤

> 跑之前写入，跑完不改。hash 冻结在 `data/prereg_7_21_premium_filter.sha256`。

- 登记时间：2026-11-02
- 来由：`output/experiments/premium_audit.csv` 首次量出真实溢价——
  跨境 ETF 加仓中位 +0.63%、减仓中位 +0.61%，**往返损耗仅 0.02%**，
  但**尾部分布很厚**：加仓溢价 P90 = **+7.21%**，即约 10% 的买入发生在 7% 以上的溢价上。
- 因此本试验不解决"系统性溢价"（那不存在），只处理**尾部**。

## 一、数据基础与限制（先写清楚，避免事后解释）

| 项 | 值 |
|---|---|
| 净值库 | `data/etf_nav_history.csv`，2021-01-04 ~ 2026-10-30 |
| 覆盖 | 260 只，溢价矩阵非空比例 70.8% |
| **2019-2020** | **无净值数据 → 该段不施加过滤，等同基线** |
| 分红失真 | 单位净值不含已分红部分，境内 ETF 除权日会出现假折价（510300 在 2024-06-20 为 −5.96%） |

**因此本试验只在 2021 年之后真正生效**，全样本结果会被前两年稀释。这一点在报告结论时必须写明。

## 二、变体（固定 2 个）

| 代号 | 规则 |
|---|---|
| **V0** | 基线（现状，不过滤） |
| **V1** | 加仓时该标的溢价 > **5%** → 跳过，取排名下一位 |
| **V2** | 加仓时该标的溢价 > **3%** → 跳过，取排名下一位 |

过滤只作用于**新买入**（含 buffer 保留的原有持仓不做强制卖出）：
理由是卖出已在溢价中，强制卖出只是把溢价风险换成交易成本。

若所有候选都超阈值：该期**少持有**，未用敞口按既有规则进债券腿（不新增规则）。

## 三、判据（预先固定）

1. **有效**：V1 或 V2 的卡玛 ≥ V0 − 0.02（不恶化），**且** 加仓溢价 P90 从 7.21% 降到 **4% 以下**。
2. **有效且有增益**：卡玛 ≥ V0 + 0.02。
3. **否**：卡玛下降超过 0.02，或 P90 未降到 4% 以下（说明过滤没起作用）。
4. 报 `2021-2026` 子区间结果作为主口径（全样本会被 2019-2020 稀释），
   但两个口径都要报，不许只挑好看的那个。

## 四、不做的事

- 不搜索阈值（3% / 5% 就这两个，跑完不改）。
- 不给"强制卖出高溢价持仓"开口子——那是另一个试验，会引入换手成本。
- 不因结果不好看而改用"累计净值"重算（分红问题只影响境内标的的判断，跨境标的不受影响，
  而尾部问题集中在跨境）。

## 五、已知风险

- **样本太小**：加仓事件仅 539 次（跨境），单边过滤可能只影响几十次交易，
  统计力有限，结果容易被单次事件主导。
- **过滤可能伤收益**：溢价高的往往是强势品种（涨得好才有人抢）。挡掉它们可能同时挡掉动量。
  这是本试验最需要观察的反向机制。
- **2019-2020 无过滤**：全样本结论必然被稀释，不能据此说"无效"。
