# 外部策略尽调清单

**用途**：拿到任何一条外部策略（视频、研报、公众号、朋友推荐）时，用这份清单在 30 分钟内给出
"值不值得投入实现"的结论。它不替代完整回测，但能在写第一行策略代码之前挡掉大部分无效工作。

**适用对象**：A 股 ETF / 指数类的选股、择时、轮动策略。
**不适用**：日内高频、套利、需要另类数据的策略（本项目的引擎与数据不支持）。

---

## 一、五道闸门（任一不过，直接降级为"不投入"）

### 闸门 1：Calmar > 3 先怀疑数据

Calmar = 年化收益 ÷ 最大回撤。

| 观察值 | 解释 |
|---|---|
| < 1 | 正常范围（本项目 TGAR 长期 0.60~0.68） |
| 1~3 | 优秀（顶级 CTA 长期水平） |
| **> 3** | **先查数据，再查运气**。本项目两次命中：7.8 视频策略 Calmar≈6（手工挑池 + 2 年窗口）；7.9 我自己第一版缠论 Calmar≈6.4（未来函数） |

判据：Calmar > 3 的策略，必须能**逐条解释每一笔交易**，否则默认不可信。

### 闸门 2：样本 < 3 年不给单点年化

年化收益的估计误差 ≈ σ/√T（T 以年计）。本类策略年化波动 15%~30%：

| 样本长度 | 95% 置信区间（σ=20%） |
|---|---|
| 2 年 | ±27.7pp |
| 3 年 | ±22.6pp |
| 8 年 | ±13.9pp |

判据：对方给的是"年化 40%"，你要问的是"波动率多少"——然后自己算区间。
**2 年样本上的 40% 与 19%/61% 在统计上分不开。**

### 闸门 3：结构类信号必须在线验证

凡是"画线、认形态、数笔、找中枢/箱体/突破"的信号，一律先问一句：
**这根线在当时画得出来吗？** 当前这根笔/趋势线/中枢的端点是临时值，事后会被替换。

- 只用**全样本端点回放**的回测，会抹掉所有假突破 → 7.9 实测虚增约 **8 倍 CAGR**（4.7% → 37.3%）、回撤少 2/3；
- 必须写成**逐日在线状态机**，并配一条因果性单测（截断未来不改变历史状态）。

本项目参考实现：`etfquant/chan.py` 的 `online_states` 与 `tests/test_chan.py::test_online_states_is_causal`。

### 闸门 4：判据先写，再看结果

把"什么情况算通过"写在脚本注释里（例如"必须 2020-22 与 2023-26 两段同向改善"），
再跑数据。先看结果再定标准，任何参数都能找到借口——本项目 7.5 的 PBO 43.2% 就是这件事的代价。

### 闸门 5：没有 IC / 归因 / 误差棒的收益数字，不算结论

这条是对**自己**的闸门，2026-10-30 补上（README 7.10）。前四道都在筛别人，
结果本项目跑了九节实验都没算过自己那条策略的 IC 和置信区间。补课之后发现：
CAGR 17.3% 里 11.2pp 是 beta、alpha 9.6pp 的 t 值只有 1.38、95% 区间是 [−1.9%, 40.9%]。
**一个没有误差棒的年化数字，信息量接近于零。**

## 二、标准实验协议（六步，约 1~2 小时）

1. **口径固定**：T 日收盘出信号、T+1 开盘成交、双边 0.10%、`min_hist ≥ 250`、
   点时（point-in-time）可用性、次新 ETF 至少 12 个月历史才参与打分。
2. **参数取最朴素的一组**，并**声明没有挑选**。参数挑过的复现，测的是你的搜索能力，不是那条规则。
3. **同起点比较**：所有变体统一从 2020-01-02 起（残差等因子有 24 个月预热），
   另加视频/原文声称的窗口与 2023-01 起两段。**不同起点比年化没有意义。**
4. **必看两段子区间**：2020-22（阴跌熊）与 2023-26（轮动牛）。只在一段赢 = 环境依赖，不是改进。
5. **邻域检验**：唯一看起来有效的那组参数，必须在邻域（±1 档）里方向一致；单点最优 = 尖峰 = 噪声。
6. **成本与换手**：年换手 > 30 倍的策略，先算 `换手 × 2 × 0.10%`，看它还剩多少超额。

> 现成脚手架：`scripts/research/ab_dual_mom.py`（月度/横截面）、`scripts/research/ab_macross.py`（择时/单标的）、
> `scripts/research/ab_momvol.py`（多因子打分）、`scripts/research/ab_chan.py`（结构类信号）、
> `scripts/research/ab_resid.py`（因子接入，含邻域扫描）。

## 三、红旗清单（看到就扣分）

| 现象 | 常见原因 | 一句话判据 |
|---|---|---|
| 只在某一段行情有效 | 环境依赖 | 换 2020-22 与 2023-26 分别看 |
| 回撤远小于同期基准 | 未来函数 / 大量空仓 / 挑池 | 满仓策略的回撤不该低于基准的一半 |
| 胜率 80%+ | 小样本 + 单边行情 | 问平均盈亏比，胜率高≠期望高 |
| 池子是"今天的热门名单" | 幸存者偏差 | 本项目池内 2019 年初只有 40 只可选（见 README 已知局限 10） |
| 规则里有"特殊情况下……" | 手工补丁 | 7.6 的"异常月扣分"在三个窗口两个为负 |
| 只给累计收益，不给年化/回撤 | 数字挑选 | 三段式索要：年化、最大回撤、年换手 |
| 参数密集（>6 个） | 过拟合预算超支 | 本项目曾一次性暴露 10 个可调参数，现已冻结（7.5） |
| "实盘已验证" | 无法核实 | 要逐笔记录，否则等于回填 |

## 五、这份清单不做什么

- 不判断策略"有没有道理"——道理讲得通但回测不成立的东西太多了；
- 不替代完整实现：通过五道闸门只说明"值得花两天实现"，不说明"能用"；
- 不能用于参数调优：清单的目的是**否证**，不是寻找。本项目的调参预算已在 7.5 用尽。
