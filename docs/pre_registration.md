# 前向验证预注册（Pre-Registration）

> **本文件一经写入不再修改。** 任何改动都会改变它的 SHA256（存于
> `data/pre_registration.sha256`），`python -m etfquant audit` 会校验并报警。
> 它的目的只有一个：防止未来"看到结果之后改判据"。

- 登记时间：2026-10-30
- 对象：S4-TGAR（20 日动量 + 趋势闸门 + 债券防守腿，5 日调仓，260 只 ETF 池）

## 一、判据（先于结果固定）

前向跟踪的唯一产出是月报第五节的「alpha 还在不在」。以下阈值是**现在**定死的：

1. 单月残差 |z| < 2 → 不解读（月残差 σ≈5.7%，±6pp 是常态）。
2. 单月 |z| ≥ 3 → 视为异常，当天查记账 / 归档 / 数据完整性。
3. 累计残差只有在满 6 个月后才折年化；此前只报累计值与标准误。
4. "证明 alpha 存在"需要约 200 个月——**前向跟踪的用途是证伪与告警，不是确认**。

## 二、停止条件（事先写好的退出规则）

满足任一，停止把该策略作为"有效策略"使用：

- **累计残差 < −10pp**（约 2 个标准误，达到 7.13 判定的噪声上限）；
- **自真实跟踪起满 36 个月，累计残差仍未转正**；
- **连续 3 个季度月报偏差（纸上 vs 回测）绝对值 > 0.5pp**——这说明执行或记账已走样，
  在修好之前不引用任何收益数字。

## 三、不做什么

- 不因前向数据"不好看"而回头调整主线参数（7.5 已裁定冻结）。
- 不因前向数据"好看"而上调对外口径（对外口径仍以 `expectation.py` 为准，11%~13%）。
- 份额数据（7.14）满 120 个交易日后的检验，按 7.14 第三节写的判据执行，不属于本文件的停止条件。
