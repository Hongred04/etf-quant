# 试验预注册 7.17 — 慢变量仓位上限（股债相对强弱分位）

> **本文件在跑任何回测之前写入，跑完不修改。** 改动会改变 SHA256（存于
> `data/prereg_7_17_slow_gate.sha256`），`python -m etfquant audit` 会校验。
> 目的与 `pre_registration.md` 相同：防止看到结果之后改判据。

- 登记时间：2026-11-01
- 来由：外部视频"股债利差 ERP 分钟宏观模型"主张用 ERP 分位三档调股债配比。
  本项目拿不到历史 PE 与国债收益率序列（腾讯行情只给 OHLCV），
  改用**价格版近似**：股债相对强弱的分位，检验同一个问题——
  **给 TGAR 的价格闸门加一个慢变量上限，有没有增量。**
- 与主线的区别：TGAR 的闸门是快变量（价格趋势 + 广度，日级）；本试验引入的是
  慢变量（月度、5 年分位），只做**仓位上限**，不替代闸门。

## 一、指标定义（先固定，不留解释空间）

| 项 | 定义 |
|---|---|
| 股端 | `sh510300` 前复权收盘 |
| 债端 | `sh511260`（十年国债ETF）前复权收盘 |
| 相对强弱 RS | `ln(股净值) − ln(债净值)`，逐日 |
| 分位 | RS 在**最近 1260 个交易日（5 年，含当日）**内的百分位排名，`rolling(1260).rank(pct=True)` |
| 慢变量采样 | 每月**最后一个交易日**取分位值，持有至下月最后一个交易日（月度更新，与视频一致） |

## 二、变体（固定 3 个，跑完不新增）

| 代号 | 规则 |
|---|---|
| **V0** | 基线 = 现有 TGAR，不加上限（对照组） |
| **V1** | 分位 < 20% → 权益仓位上限 50% |
| **V2** | 分位 < 20% → 上限 50%；分位 < 10% → 上限 0% |

**上限施加方式（固定）**：若当日权益总权重 > 上限，按比例缩放全部权益列；
腾出的敞口按当日原有债券列配比补入；当日无债券列则补入 `sh511260`。

## 三、判据（预先固定）

1. **有效**：卡玛比率提升 ≥ 0.05 **且** 最大回撤改善 ≥ 1.0pp **且** CAGR 下降 ≤ 0.5pp。
2. **显著**：随机对照 200 次（把 RS 序列做循环平移，保留自相关、破坏与股票收益的时间对齐）
   中，真实方案的卡玛提升排在前 10%。
3. **稳健**：2020-01~2022-12 与 2023-01~2026-10 两段的卡玛变化同号。
4. 三条全满足才算"有效且显著"，否则结论为**否**，并如实写入 README 第七章。

## 四、不做的事

- 不搜索阈值（20% / 10% 就这两个，跑完不改）。
- 不修改 TGAR 任何参数；不因子样本结果回头调整规则。
- 不在事后追加变体（追加即为多重比较，会让 7.5 的 PBO 结论失效）。

## 五、已知的先验风险

- 5 年滚动分位在利率单边下行期会系统性偏移（RS 的股端是价格、债端也是价格，
  但债券价格的长期上行会压低 RS 中枢），可能使"分位 <20%"长期不触发，
  变体退化为基线——若如此，如实记为"无增量"，不视为失效。
- 慢变量若与价格闸门高度相关，增量必然趋近于零；这正是要测的。
