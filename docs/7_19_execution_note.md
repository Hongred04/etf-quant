## 三、为什么（跑之前没有核实）

预注册依据的是快照：945 只 ETF、成交额 >2000 万 721 只。但真实链路还有两道过滤：

| 环节 | 剩余 |
|---|---|
| 快照总数 | 945 |
| 剔除货币（24 只） | 921 |
| **`dedup_same_index` 去同指数重复** | **305（去掉 616 只）** |
| 成交额 > 2000 万 | 257 |
| 成交额 > 1000 万 | 290 |

**`dedup_same_index` 砍掉了 616 只**——沪深300、中证500、创业板等主流指数各有十几只同质 ETF，
只保留一只。这一层在预注册时被我完全忽略了，所以"扩到 721"是一个不存在的空间。

另外核实到：**现有池 260 只全部包含在 305 只候选里，0 只缺失**。
也就是说现有池并不是"人为收窄"，它已经接近"去重后 + 流动性达标"的全集。

预注册的判据（卡玛提升 ≥ 0.03、CAGR 降 ≤ 0.5pp、2x 成本下卡玛 ≥ 基线 1x 的 80%）
